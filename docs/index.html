Setup builder

Two things to set up: the machine that runs everything, and the board that reads the sensors. Do them in order — the board needs the server's address. Nothing is sent anywhere; this page runs entirely in your browser.

Sets up the machine that runs everything. Choose your timezone and logins, press the button, and this writes out every step with your own settings in place. Leave anything blank and it uses admin / admin123.

The ESP32 board is the other tab above. Do the server first.

Timezone

Timers run on this clock. Wrong timezone means watering at the wrong hour.

Fixed address — optional, leave blank to skip

By default your router hands the server an address that can change after a power cut, and then every board loses it. Setting a fixed one avoids that. Leave blank and the guide uses whatever address the server already has.

Logins

Used by nodered, mysql, influxdb and grafana.
nodered The dashboard editor, where the logic lives
mysql Stores devices, rules and schedules
influxdb Stores sensor readings over time
grafana Graphs of that history
mysql root Emergency database access. Never used day to day.
mqtt How the ESP32 board connects. Typed on the board's setup page too.
Username is always mqtt.

Server

Encryption — advanced, only for a server on the internet

On your own network this is unnecessary — nothing leaves the building. Turn it on only if the server is reachable from the internet, where the board's password would otherwise cross it in plain text.
